# agent-playground

## Installation

### Requirements

- [Git](https://git-scm.com/downloads)

### Clone the repository

Use HTTPS:

```bash
git clone https://github.com/ditshej/agent-playground.git
cd agent-playground
```

Or use SSH:

```bash
git clone git@github.com:ditshej/agent-playground.git
cd agent-playground
```

### Get started

1. Make a new branch for your work:

   ```bash
   git checkout -b my-change
   ```

2. Make your changes.

3. Commit and push the branch:

   ```bash
   git add .
   git commit -m "Describe your change"
   git push -u origin my-change
   ```

4. Open a pull request against `main`.
